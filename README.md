# Amazon Sales Dashboard – Power BI

## Project Overview

Developed an interactive Amazon Product Analysis Dashboard using Microsoft Power BI to analyze product prices, discounts, ratings, customer reviews, and product categories.

## Objectives

* Analyze product prices and discounts.
* Identify popular product categories.
* Understand customer ratings and reviews.
* Compare actual and discounted prices.
* Explore product performance and customer preferences.

## Tools Used

* Microsoft Power BI
* Microsoft Excel
* CSV Dataset

## Key Features

* Product category analysis.
* Price and discount analysis.
* Customer rating analysis.
* Product review insights.
* Interactive filters and visualizations.

## Dataset

The project uses an Amazon product dataset containing 1,465 records and 16 columns.
